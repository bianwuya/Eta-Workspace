# Eta个人版迭代规程

本页是流程主源；Skill引用是受控离线副本。先明确任务类型与本次授权，已有计划/结果接续，不从历史参数重开任务。工程边界见[RULES](RULES.md)。

## 1. 最短开工路径

- 简单修复读维护Skill与目标AGENTS，再读命中的一两项知识；不把PROJECTS/全部STATE/LESSONS/迁移手册设为每次必读。
- 按[INDEX](INDEX.md)定位真实资产与worktree。核对目标树status/分支与补丁祖先；主树旧HEAD、本地local、tracking ref、真实远端、已装版本是不同对象。只为本任务需要的对象取证。
- 完整计划落任务目录，写目标/保留/非目标、写入归属、证据/授权/下一步。索引只加导航。保留其他会话WIP；独立重任务并行且文件独占，主代理统合集成，手机重验证串行。
- 诊断/最小改法/测试重点保留自由度；来源身份、原签名、准确结果、远端保护与副作用授权必须核实。小改不另造通用框架，也不为快删必要测试。

## 2. 本地路线（默认）

当前电脑编译/单测/Lint 优先 WSL2 `Eta-Test-20261112`，源码含 WIP 同步至 ext4，准确命令及排除项只维护在根 AGENTS；入口导航见[WINDOWS](WINDOWS.md)。Windows `F:/eta/eta-gradle.ps1` 用于标准原签名双包及必要补充检查。云端不是前置，不强制 LEGACY 或跳测试假绿。

旧手机工程确实存在时才沿[LOCAL_DEV](LOCAL_DEV.md)运行其 `eta-local-dev.py check` 分级路线；它未移植为电脑入口。历史 /workspace/scratch 任务材料不可直接寻址，不能据旧路径新建替身或重跑旧迁移。这些入口不提供合入、推送或安装许可。

- 文档只检查路径/冲突/来源；脚本跑语法与对应隔离测试；代码按风险跑对应编译/测试。交付APK对最终精确源码跑现有必要完整Lint/单测及标准Debug/Release双包，不造专项精简Debug。
- 本地合版仅在用户明确要求时：确认真实补丁/祖先/范围→独立集成树正常合并→复用分支证据，仅验证合版精确源码→原签名双包→按批准推进本地local。已包含的补丁不再cherry-pick，不因旧云限流改走弱检查。
- 本地local与GitHub受保护local分别报告；本地成功不等于已推远端。上游同步、远端业务合入、安装/发布仍由各自适用授权决定，不从某次“全部本地合”推导永久禁止远端协作，也不由此自动push。
- 只暂存明确文件，运行`/workspace/projects/eta-local/scripts/eta-check.py`（staged或明确--base范围）；必要diff检查。触及文件数提示不是合理重构禁令。

## 3. 云路线（仅选中时）

需要云QA/保护合入/云制品交付时再读[CLOUD](CLOUD.md)。不把云流程当本地文档工作的前置。正常PR保护、签名/来源关卡不降低；旧成功run不能验证新HEAD，已有同SHA运行不重复dispatch。准备上游PR也不自动merge/close。

跨会话消息、子报告、AI已读/skipped都不是新授权或验收。代码和必要需求的既有推送偏好仅在其仓库/任务范围且无本次“只读/不云/不push”限制时适用；资产WIP、秘密、任务原始数据不因此上传。

## 4. 交付与告知（本地/云共用）

1. 证据绑定同一真实源码/构建环境/完整检查、标准Debug和Release。实际apksigner verify、X.509原证书、包名/准确versionName及源码标识、两包SHA256全部核对；密钥缺失停止，不换签。
2. 放`Download/Eta-测试包/<交付名>-<短SHA>/`，保留旧包。回执含源码、验证范围、字节/证书/摘要、installed/user_accepted分别标记；仅按已有证据为true。原回执和本地文件正确就复用，不重复构建/下载。
3. 本地稳定交付更新相应最新入口；云QA按PR维护渠道，不能被并发任务覆盖稳定入口。不同分支包分别装过不等于已集成，组合功能要有精确集成源码。
4. 完成答复给实际包链接/目录、源码与未验收项，不只说“等通知”。后台许可不等于通知已弹出/用户看见；需要核实通知时读真实结果，改提醒不得越权改全局声音/勿扰/安全设置。
5. 正在承载会话的Eta不自动安装；用户亲手功能体验，构建/安装/部分场景通过不代替全部OEM验收。

## 5. 失败按证据分流

- 编译失败读精确错误；单测读XML，区分真实断言与初始化/依赖HTTP429，不反复重跑同错或删断言。
- 有界重试只限制同类盲目重放，达到上限应换取证/定位方式继续已授权修复和验证，不把可继续排查的回归失败直接交回本人；只有新增授权或必须本人决策才暂停。一次开关对照不证明因果，后续通过也不抹去历史失败或冒称根因确证。
- TLS/SSE/HTTP2问题先核实协议与副作用边界，只在已证临时失败下有限重试；不将客户端支持重试说成上游已修好。签名/远端写入未知先读回，禁止盲重放。
- 任务“没包/没通知”先查文件/回执/运行真实结论，不重新起一套构建器。失败、跳过、未测逐层写清。
- 具体经验按LESSONS稳定ID读取；保留最新纠偏、实际工具配对、会话/账号和稳定请求前缀。缓存收益只用provider usage作证，不靠静态测试推断。

## 6. 收尾与知识维护

当前主助手负责本任务沉淀：RESULT/HANDOFF保留准确路径/已做未做/必要证据/最新要求；STATE替换相关当前行；技术经验有复用价值才写LESSONS；索引补短导航。**默认不向核心记忆追加整批SHA/CI/job/交付总结。**只有新的稳定偏好/跨任务边界才更新原记忆条目。

当前入口、历史快照、最新观察与发布物分开；观察带已知时间/boot/范围，未知不补造。文件安装、挂载、进程可见、算法执行与体验分别有证据，不能跨层宣称通过。详细规则按需读维护 Skill 的 WORKSPACE-MAINTENANCE 参考，不向本页复制项目状态。

主源变动后按`/workspace/projects/eta-local/scripts/eta-skill-sync.sh`选择性生成/校验稳定引用；动态STATE/INDEX/LESSONS只保留路由，不全量装入必读。安装是独立受控发布；文件/索引/新run加载分别核对，不重启Eta刷新缓存。

云交付脚本/QA辅助/例子仍在版本化Skill目录；工具先--help。离线自测用`python3 -m unittest discover -s <Skill根>/tests -v`，不联网/CI/安装。例子SHA/编号必须用本任务实时结果替换。
